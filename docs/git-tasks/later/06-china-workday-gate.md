# C6：中国工作日 Gate

## 目的

仅在明确存在面向中国团队的工作日通知、日报或审批节奏时，阻止非工作日的无效定时任务执行。

## 价值与意义

- 避免周末、法定节假日和调休期间打扰人员或产生无意义报表。
- 将“是否应该执行”从散落的 cron 注释变为可测试的统一策略。

## 触发条件与前置条件

- 至少一条 DeepAuto 非核心业务任务明确要求中国工作日才执行。
- 已有可靠的节假日/调休数据来源和数据更新责任人。
- 任务可安全跳过，且跳过记录不会破坏统计时间窗。

## 实现方案

1. 将 Gate 作为独立、只读的 schedule 前置步骤，不与代码 Execution 主链路耦合。
2. 定义节假日数据来源、缓存时间、失败策略和人工 override。
3. 在 summary 中写明本轮执行或跳过的日期与判据。
4. 为节假日、补班、数据源不可用和手动补跑编写测试。

## 验收策略

- 普通工作日、周末、法定节假日和调休补班日结果符合预期。
- 日历数据不可用时按事先决定的 fail-open 或 fail-closed 策略处理，并产生可见告警。
- 不影响任何用户主动发起的 Execution。

## 人工决策

- 是否真的需要该能力；没有明确业务流程时不应实现。
- 日历服务故障时选择跳过还是执行；通知类任务通常 fail-closed，关键合规任务需单独决定。

## 当前不做原因

代码任务执行不应依赖工作日；当前没有需要按法定工作日运行的运营自动化。
