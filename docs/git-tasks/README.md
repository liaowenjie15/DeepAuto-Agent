# GitHub 自动化复用任务索引

本目录把 `09-grain-github-automation-reuse-decision.md` 中的每一项决策拆成独立任务。任务文档是实施与验收的唯一入口；它们不改变 DeepAuto 已定的控制面、PR-only 交付和最小权限原则。

| 分组 | 含义 | 任务数 |
| --- | --- | --- |
| [`now/`](./now/) | 当前可落地的安全与验证基线 | 4 |
| [`adapt/`](./adapt/) | 问题定义可复用、实现必须以 DeepAuto 控制面重写 | 7 |
| [`later/`](./later/) | 仅在明确规模或产品条件满足后评估 | 6 |
| [`not-reuse/`](./not-reuse/) | 不迁移的能力边界与防回流约束 | 8 |

实施顺序：先完成 `now/`，再按代码任务执行闭环推进 `adapt/`；任何 `later/` 任务必须先满足其文档中的触发条件。`not-reuse/` 不产生功能代码，其价值是阻止错误的复制与架构回流。
